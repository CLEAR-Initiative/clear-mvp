# Location trust: challenge without forced candidates

Location verification wastes analyst time when pins (especially Dataminr) are wrong and place names have local spellings. We considered auto-suggesting top‑3 gazetteer matches and forcing a pick. We decided **not** to: v1 lets analysts **Location challenge** a **Signal** and optionally submit a **Location correction** (proposed point) for queued **consideration**, with **dual location display** only when a proposed point exists. Accept/reject belongs to a future **Location admin** role — not this wedge. See `CONTEXT.md` (Location trust).
